# Vibe-code template lineage

Apex Grid uses the architecture conventions of the **Vercel shadcn/ui Registry Starter**: Next.js App Router, open-code components, a `components.json` registry manifest, server-first rendering, and agent-friendly aliases.

The visual design and racing components in this repository are original. No third-party premium template assets are redistributed.

## Compatible workflows

- v0: import the Git repository, then ask v0 to modify individual App Router pages or components.
- Cursor / Claude Code / Codex: use `AGENTS.md` as the implementation contract.
- shadcn CLI: `components.json` allows safe addition of registry components without replacing the custom design system.

Source reference: https://vercel.com/templates/next.js/shadcn-ui-registry-starter
